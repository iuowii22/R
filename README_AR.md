# FluentUp — فلوينت أب

منصة ويب تعليمية عربية لتعلم الإنجليزية تدريجيًا. هذه حزمة مشروع قابلة للتشغيل والتطوير، وليست موقعًا منشورًا. بعض الخدمات الخارجية اختيارية وتحتاج إلى إعداد مفاتيح وحسابات قبل تفعيلها.

## الموجود في هذه الحزمة

- واجهة عربية متجاوبة مبنية بـ Next.js وReact وTypeScript.
- 50 درسًا تعليميًا من A1 إلى C1: 15 درس تأسيسي A1 و35 درسًا إضافيًا موزعة على A2 وB1 وB2 وC1. تتضمن الدروس شرحًا بالعربية وأمثلة مترجمة وأسئلة تحقق قصيرة.
- أربع مهارات: استماع مع مقاطع ونصوص وأسئلة فهم، تدريب تحدث باستخدام التعرف الصوتي في المتصفح عند دعمه، قراءة مع أسئلة، وكتابة يمكن إرسالها للمعلّم لتصحيحها.
- 50 بطاقة مفردات مع معنى عربي ومثال.
- اختبار يومي من 10 أسئلة مع تفسير الإجابات.
- معلّم محادثة نصي مع نقطة API خادمية متصلة بواجهة OpenAI Responses API عند إضافة مفتاح API صالح.
- قراءة النصوص بصوت المتصفح عبر SpeechSynthesis حيثما تدعم البيئة ذلك.
- تسجيل دخول/إنشاء حساب اختياري عبر Supabase Auth، وحفظ إكمال الدروس في جدول Supabase عند ضبط المشروع ومخطط قاعدة البيانات. من دون إعداد Supabase يعمل التقدم محليًا على الجهاز.
- مخطط SQL يتضمن سياسات RLS أساسية لبيانات المستخدم.

## متطلبات التشغيل

- Node.js 20 أو أحدث.
- اتصال إنترنت لتنزيل الحزم وتشغيل الخدمات الخارجية.
- مفتاح API لمزود الذكاء الاصطناعي إذا أردت تفعيل الردود الذكية الحقيقية؛ الاستخدام قد يترتب عليه رسوم.
- مشروع Supabase إذا أردت الحسابات والمزامنة السحابية.

## التشغيل محليًا

1. فك الضغط وافتح مجلد `fluentup-starter` في الطرفية.
2. نفّذ `npm install` وانتظر اكتمال تنزيل الحزم.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف `OPENAI_API_KEY` في `.env.local` لتفعيل المعلّم الذكي. يمكن ضبط `OPENAI_MODEL` على نموذج متاح في حسابك.
5. شغّل `npm run dev` وافتح `http://localhost:3000`.
6. اختبر نسخة الإنتاج عبر `npm run build` قبل النشر.

## تفعيل الحسابات والمزامنة السحابية

1. أنشئ مشروع Supabase.
2. نفّذ محتوى `supabase/schema.sql` في SQL Editor.
3. أضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` إلى `.env.local`.
4. أعد تشغيل الخادم واختبر إنشاء حساب وتسجيل الدخول وحفظ إكمال الدرس.
5. اضبط إعدادات تأكيد البريد وسياسة كلمة المرور في Supabase وفق متطلبات الإطلاق.

لا تضع مفتاح OpenAI أو Supabase service-role في متغير يبدأ بـ `NEXT_PUBLIC_`، ولا ترفع `.env.local` إلى GitHub.

## حدود معروفة يجب اختبارها قبل الإطلاق

- الصوت الحالي يعتمد على قدرات المتصفح: تحويل الكلام إلى نص وقراءة النص، وليس محادثة صوتية منخفضة التأخير في الزمن الحقيقي ولا تقييمًا احترافيًا للنطق.
- المنهج الحالي أساس منظم قابل للتوسيع، وليس بديلًا عن مراجعة تربوية كاملة أو اختبار CEFR رسمي. ينبغي مراجعة جميع الأسئلة والأجوبة وتوسيع التدريبات قبل التسويق بأنه منهج شامل معتمد.
- لا توجد حاليًا بوابة دفع أو لوحة إدارة محتوى أو حدود استخدام متقدمة للمستخدمين.
- قبل فتح الموقع للجمهور، أضف تحديد معدل الطلبات وحصصًا يومية للذكاء الاصطناعي، واختبارات أمنية، ومعالجة أخطاء ومراقبة تكلفة، وسياسة خصوصية وشروط استخدام.
- لم يتم نشر الموقع على الإنترنت ولم يتم إنشاء تطبيق iPhone في هذه الحزمة.

## الملفات الأساسية

- `app/page.tsx`: واجهة المنصة والمهارات والاختبارات والحسابات.
- `app/curriculum.ts`: محتوى المنهج والأسئلة.
- `app/api/tutor/route.ts`: الاتصال الخادمي بمزود الذكاء الاصطناعي.
- `lib/supabase.ts`: عميل Supabase اختياري.
- `app/globals.css`: تصميم متجاوب.
- `supabase/schema.sql`: الجداول وسياسات الوصول.
- `.env.example`: أسماء إعدادات البيئة بلا مفاتيح سرية.
